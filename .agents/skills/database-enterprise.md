# Database Enterprise

## Descripción
Habilidad para el diseño, implementación y optimización de bases de datos empresariales relacionales y NoSQL.

## Bases de datos relacionales
- **PostgreSQL**: JSONB, particionamiento, réplicas, extensiones
- **MySQL/MariaDB**: InnoDB, optimización de queries, clustering
- **SQL Server**: T-SQL, AlwaysOn, columnstore
- **Oracle**: PL/SQL, RAC, particionamiento

## Bases de datos NoSQL
- **MongoDB**: Aggregation framework, sharding, réplica sets
- **Redis**: Caching, pub/sub, estructuras de datos
- **Elasticsearch**: Búsqueda full-text, analytics, ELK Stack
- **Cassandra**: Distribución, alta disponibilidad
- **DynamoDB**: Serverless, key-value, diseño de esquemas

## Modelado de datos
- Normalización (1NF, 2NF, 3NF, BCNF)
- Denormalización controlada
- Diagramas ER (ERD)
- Data Warehouse y Data Lakes
- OLTP vs OLAP
- Star Schema y Snowflake Schema

## Optimización
- Indexación estratégica
- Query optimization y EXPLAIN
- Partitioning y sharding
- Connection pooling
- Read replicas
- Caching strategies (Redis, Memcached)

## Migraciones
- Flyway, Liquibase, Alembic
- Migraciones versionadas
- Rollback strategies
- Zero-downtime migrations

## Backup y recuperación
- Backup automatizados (full, incremental, differential)
- Point-in-time recovery (PITR)
- Disaster recovery planning
- RPO y RTO

## Seguridad
- Cifrado en reposo (TDE)
- Cifrado en tránsito (TLS)
- Auditoría de accesos
- Row-level security
- Data masking
