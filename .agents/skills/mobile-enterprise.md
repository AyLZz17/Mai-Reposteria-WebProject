# Mobile Enterprise

## Descripción
Habilidad para el desarrollo de aplicaciones móviles empresariales nativas y multiplataforma.

## Desarrollo nativo

### iOS
- **Lenguajes**: Swift, Objective-C
- **Frameworks**: UIKit, SwiftUI, Combine
- **Arquitecturas**: MVC, MVVM, VIPER, Clean Architecture
- **Herramientas**: Xcode, CocoaPods, Swift Package Manager
- **Testing**: XCTest, XCUITest

### Android
- **Lenguajes**: Kotlin, Java
- **Frameworks**: Jetpack Compose, Android Views, Coroutines, Flow
- **Arquitecturas**: MVVM, MVI, Clean Architecture
- **Herramientas**: Android Studio, Gradle
- **Testing**: JUnit, Espresso, UI Automator

## Desarrollo multiplataforma

### React Native
- Componentes y navegación
- Native modules
- Hermes engine
- CodePush para OTA updates
- Flipper para debugging

### Flutter
- Widgets y state management (Riverpod, Bloc)
- Platform channels
- Hot reload
- Dart programming

### .NET MAUI / Xamarin
- C# y XAML
- Native API access
- MVVM pattern

### Kotlin Multiplatform (KMP)
- Shared business logic
- Native UI
- Ktor para networking
