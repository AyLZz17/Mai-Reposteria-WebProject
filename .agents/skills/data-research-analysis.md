# Investigación y Análisis de Datos

## Descripción
Habilidad para investigar, recopilar y analizar datos para extraer insights y tomar decisiones basadas en evidencia.

## Cuándo usarla
- Para analizar datos de usuarios o del sistema
- Para investigar problemas de rendimiento
- Para validar hipótesis con datos
- Para generar reportes y dashboards

## Herramientas
- **Análisis estadístico**: Python (pandas, scipy, statsmodels), R
- **Visualización**: matplotlib, seaborn, Plotly, Tableau, Power BI
- **Bases de datos**: SQL, Elasticsearch, BigQuery
- **Big data**: Spark, Dask, Hadoop
- **Herramientas ETL**: Apache Airflow, dbt, Talend

## Receta

### 1. Definir la pregunta o hipótesis
- ¿Qué quieres descubrir o validar?
- ¿Qué métricas son relevantes?
- ¿Qué decisiones se tomarán con los resultados?

### 2. Identificar fuentes de datos
- Bases de datos internas
- APIs externas
- Logs del sistema
- Encuestas o datos de usuarios
- Datos públicos o de terceros

### 3. Recopilar datos
- Extraer datos de fuentes identificadas
- Documentar procedencia y calidad
- Almacenar de forma reproducible
- Respetar privacidad y regulaciones (GDPR, etc.)

### 4. Limpiar y preparar datos
- Manejar valores nulos y outliers
- Normalizar formatos
- Eliminar duplicados
- Validar integridad

### 5. Analizar datos
- Análisis exploratorio (EDA)
- Estadísticas descriptivas
- Correlaciones y tendencias
- Tests de hipótesis
- Segmentación y clustering

### 6. Visualizar resultados
- Gráficos apropiados para cada tipo de datos
- Dashboards interactivos
- Storytelling con datos
- Anotaciones y contexto

### 7. Documentar y comunicar
- Metodología utilizada
- Hallazgos principales
- Limitaciones de los datos
- Recomendaciones accionables

## Errores típicos
- ❌ Analizar datos sin definir preguntas claras
- ❌ Ignorar la calidad de los datos (garbage in, garbage out)
- ❌ Confundir correlación con causalidad
- ❌ No documentar la procedencia de los datos
- ❌ Visualizaciones engañosas (escales truncadas, etc.)
- ❌ Ignorar sesgos en los datos
- ❌ No considerar el tamaño muestral

## Checklist
- [ ] Pregunta o hipótesis definida
- [ ] Fuentes de datos identificadas
- [ ] Datos recopilados y documentados
- [ ] Datos limpiados y validados
- [ ] Análisis estadístico realizado
- [ ] Visualizaciones creadas
- [ ] Hallazgos documentados
- [ ] Limitaciones identificadas
- [ ] Recomendaciones formuladas
