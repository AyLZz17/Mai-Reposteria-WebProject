# Investigación Cuantitativa de Usuarios

## Descripción
Habilidad para diseñar y ejecutar estudios cuantitativos que midan comportamientos, preferencias y métricas de usuarios a escala.

## Cuándo usarla
- Para validar hallazgos cualitativos con datos estadísticos
- Para medir el impacto de cambios en el producto
- Para segmentar usuarios por comportamiento
- Para priorizar funcionalidades por demanda

## Herramientas
- **Encuestas**: Typeform, SurveyMonkey, Google Forms, Qualtrics
- **Analítica**: Google Analytics, Mixpanel, Amplitude, Hotjar
- **Tests A/B**: Optimizely, VWO, Google Optimize, LaunchDarkly
- **Estadística**: R, Python (scipy, statsmodels), SPSS, Excel

## Métodos cuantitativos

### Encuestas
- **Cuándo**: Para recopilar datos de muchos usuarios rápidamente
- **Tipos**: Satisfacción (CSAT, NPS, SUS), preferencias, demografía
- **Tamaño muestral**: Mínimo 100-200 para significancia estadística
- **Mejores prácticas**: Preguntas claras, escalas consistentes, evitar sesgos

### Analítica de producto
- **Métricas de producto**: DAU/MAU, retención, conversión, churn
- **Funnels**: Identificar puntos de abandono
- **Cohortes**: Analizar comportamiento por grupos
- **Segmentación**: Comparar grupos de usuarios

### Tests A/B
- **Cuándo**: Para comparar variantes de diseño o funcionalidad
- **Hipótesis**: Definir qué se espera mejorar y por qué
- **Tamaño muestral**: Calcular antes del test (power analysis)
- **Duración**: Mínimo 1-2 semanas para evitar sesgos temporales

### Análisis de datos existentes
- **Logs del sistema**: Patrones de uso, errores, rendimiento
- **Datos de negocio**: Ventas, soporte, feedback
- **Datos de terceros**: Benchmarks de industria

## Receta

### 1. Definir la pregunta de investigación
- ¿Qué quieres medir o validar?
- ¿Qué decisión informará este estudio?
- ¿Cuál es la hipótesis?

### 2. Seleccionar el método apropiado
- **Encuestas**: Actitudes, preferencias, satisfacción
- **Analítica**: Comportamiento real, métricas de producto
- **Tests A/B**: Comparar variantes, medir impacto
- **Análisis de datos**: Explorar patrones existentes

### 3. Diseñar el estudio
- Definir población objetivo y muestra
- Calcular tamaño muestral necesario
- Diseñar instrumento (encuesta, test, etc.)
- Definir métricas y KPIs

### 4. Recopilar datos
- Ejecutar encuesta, test o análisis
- Asegurar calidad de los datos
- Documentar metodología y limitaciones
- Respetar privacidad y consentimiento

### 5. Analizar resultados
- Estadísticas descriptivas (media, mediana, desviación)
- Tests de hipótesis (t-test, chi-cuadrado, ANOVA)
- Intervalos de confianza
- Análisis de significancia estadística

### 6. Interpretar y comunicar
- ¿Los resultados son estadísticamente significativos?
- ¿Son prácticamente significativos (tamaño del efecto)?
- ¿Qué implicaciones tienen para el producto?
- Visualizaciones claras de los hallazgos

### 7. Tomar decisiones basadas en datos
- Priorizar acciones por impacto
- Validar o refutar hipótesis
- Identificar áreas para investigación adicional
- Documentar decisiones y justificación

## Errores típicos
- ❌ Tamaño muestral insuficiente (resultados no significativos)
- ❌ No definir hipótesis antes de recopilar datos
- ❌ Confundir correlación con causalidad
- ❌ Ignorar sesgos de selección o respuesta
- ❌ No calcular el tamaño muestral necesario
- ❌ Tests A/B sin duración o muestra suficiente
- ❌ No considerar variables de confusión
- ❌ Generalizar resultados inadecuadamente

## Checklist
- [ ] Pregunta de investigación definida
- [ ] Hipótesis formulada
- [ ] Método apropiado seleccionado
- [ ] Tamaño muestral calculado
- [ ] Instrumento diseñado y validado
- [ ] Datos recopilados con calidad
- [ ] Análisis estadístico realizado
- [ ] Significancia estadística verificada
- [ ] Resultados interpretados correctamente
- [ ] Decisiones documentadas
