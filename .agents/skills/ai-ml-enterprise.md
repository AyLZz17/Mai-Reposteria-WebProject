# AI/ML Enterprise

## Descripción
Habilidad para la integración de inteligencia artificial y machine learning en aplicaciones empresariales.

## Machine Learning

### Frameworks y librerías
- **Python**: scikit-learn, XGBoost, LightGBM, CatBoost
- **Deep Learning**: TensorFlow, PyTorch, Keras
- **NLP**: spaCy, NLTK, Hugging Face Transformers
- **Visión computacional**: OpenCV, YOLO, Detectron2

### Tipos de ML
- Supervisado (clasificación, regresión)
- No supervisado (clustering, reducción de dimensionalidad)
- Refuerzo (Q-learning, policy gradients)
- Semi-supervisado y self-supervisado

### MLOps
- **Experiment tracking**: MLflow, Weights & Biases, Neptune
- **Feature stores**: Feast, Tecton
- **Model serving**: TensorFlow Serving, TorchServe, Triton, Seldon
- **Pipelines**: Kubeflow, Airflow, Prefect, Dagster
- **Monitoring**: Evidently, WhyLabs, Arize AI
- **Versionado de datos**: DVC, LakeFS

## Inteligencia Artificial Generativa

### LLMs (Large Language Models)
- OpenAI API (GPT-4, GPT-3.5)
- Anthropic Claude
- Google Gemini
- Open source: Llama, Mistral, Falcon

### Patrones de integración
- RAG (Retrieval-Augmented Generation)
- Prompt engineering
- Fine-tuning (LoRA, QLoRA)
- Function calling / Tool use
- Agents y multi-agentes
- Embeddings y vector search

### Bases de datos vectoriales
- Pinecone, Weaviate, Milvus, Qdrant
- pgvector, Chroma, FAISS

## Visión e IA multimodal
- OCR (Tesseract, AWS Textract, Google Vision)
- Reconocimiento facial
- Análisis de imágenes y video
- Modelos multimodales (CLIP, GPT-4V)

## IA en producción
- Escalabilidad de inferencia
- Edge computing
- GPU/TPU optimization
- Batch vs real-time inference
- A/B testing de modelos
- Model rollback

## Ética y gobernanza
- Sesgo y equidad
- Explicabilidad (XAI)
- Privacidad (differential privacy, federated learning)
- Cumplimiento regulatorio (EU AI AI)
- Responsible AI framework
