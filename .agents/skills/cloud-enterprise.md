# Cloud Enterprise

## Descripción
Habilidad para el diseño, implementación y gestión de soluciones en la nube empresarial.

## AWS (Amazon Web Services)

### Computación
- EC2, ECS, EKS, Lambda, Fargate
- Auto Scaling Groups
- Elastic Load Balancing

### Almacenamiento
- S3, EBS, EFS, Storage Gateway
- Versionado y lifecycle policies

### Bases de datos
- RDS, DynamoDB, ElastiCache, Redshift, DocumentDB, Neptune

### Redes
- VPC, Subnets, Security Groups, NACLs
- Route 53, CloudFront, API Gateway
- Direct Connect, VPN

### Seguridad
- IAM, KMS, Secrets Manager, WAF, Shield
- CloudTrail, Config, GuardDuty
