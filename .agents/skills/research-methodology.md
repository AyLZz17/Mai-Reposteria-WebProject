# Metodología de Investigación

## Descripción
Habilidad para diseñar y ejecutar investigaciones sistemáticas, rigurosas y reproducibles en cualquier dominio.

## Cuándo usarla
- Al iniciar cualquier proyecto de investigación
- Para asegurar rigor metodológico
- Para diseñar experimentos o estudios
- Para documentar procesos de investigación

## Herramientas
- **Diseño de investigación**: Cualitativo, cuantitativo, mixto
- **Métodos**: Estudios de caso, encuestas, experimentos, etnografía
- **Herramientas**: R, Python, SPSS, NVivo, Atlas.ti
- **Gestión**: Zotero, Notion, Obsidian, Trello

## Tipos de investigación

### Investigación exploratoria
- **Propósito**: Explorar un tema poco conocido
- **Métodos**: Revisión de literatura, entrevistas, focus groups
- **Cuándo**: Al inicio de un proyecto, para entender el problema

### Investigación descriptiva
- **Propósito**: Describir características de un fenómeno
- **Métodos**: Encuestas, observación, estudios de caso
- **Cuándo**: Para documentar el estado actual

### Investigación explicativa
- **Propósito**: Explicar causas y efectos
- **Métodos**: Experimentos, análisis causal
- **Cuándo**: Para entender por qué algo ocurre

### Investigación evaluativa
- **Propósito**: Evaluar la efectividad de una solución
- **Métodos**: Tests A/B, métricas, análisis de impacto
- **Cuándo**: Para medir resultados de una intervención

## Receta

### 1. Definir el problema de investigación
- Pregunta de investigación clara y específica
- Hipótesis (si aplica)
- Variables independientes y dependientes

### 2. Revisar literatura existente
- Búsqueda sistemática de estudios previos
- Identificar gaps en el conocimiento
- Fundamentar la investigación en teoría existente

### 3. Diseñar la investigación
- Seleccionar tipo de investigación
- Definir población y muestra
- Elegir instrumentos de medición
- Planear análisis de datos

### 4. Recopilar datos
- Obtener permisos necesarios (ética, privacidad)
- Aplicar instrumentos de medición
- Asegurar calidad de los datos
- Documentar el proceso

### 5. Analizar datos
- Análisis estadístico apropiado
- Triangulación de fuentes (si es mixto)
- Validar resultados
- Identificar limitaciones

### 6. Interpretar y comunicar resultados
- Relacionar hallazgos con la literatura
- Formular conclusiones basadas en evidencia
- Identificar implicaciones prácticas
- Sugerir futuras líneas de investigación

### 7. Asegurar reproducibilidad
- Documentar metodología completa
- Compartir datos (si es posible)
- Publicar código y materiales
- Registrar previamente (pre-registration)

## Errores típicos
- ❌ Pregunta de investigación vaga o demasiado amplia
- ❌ No revisar literatura existente
- ❌ Tamaño muestral insuficiente
- ❌ Sesgo de selección o de confirmación
- ❌ No considerar variables de confusión
- ❌ Generalizar resultados inadecuadamente
- ❌ No documentar limitaciones
- ❌ No asegurar reproducibilidad

## Checklist
- [ ] Problema de investigación definido
- [ ] Literatura revisada
- [ ] Metodología diseñada
- [ ] Permisos éticos obtenidos (si aplica)
- [ ] Datos recopilados sistemáticamente
- [ ] Análisis realizado rigurosamente
- [ ] Resultados interpretados correctamente
- [ ] Limitaciones documentadas
- [ ] Reproducibilidad asegurada
