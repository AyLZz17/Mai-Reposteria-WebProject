# Project Management Enterprise

## Descripción
Habilidad para la gestión de proyectos de software empresariales con metodologías ágiles y tradicionales.

## Metodologías ágiles

### Scrum
- Roles: Product Owner, Scrum Master, Development Team
- Eventos: Sprint Planning, Daily Scrum, Sprint Review, Sprint Retrospective
- Artefactos: Product Backlog, Sprint Backlog, Increment
- Velocidad y burndown charts

### Kanban
- Visualización del flujo
- WIP (Work In Progress) limits
- Pull system
- Continuous delivery
- Cumulative flow diagram

### SAFe (Scaled Agile Framework)
- Agile Release Trains (ARTs)
- Program Increment (PI) Planning
- System Teams
- Lean-Agile leadership

### Lean Startup
- Build-Measure-Learn
- MVP (Minimum Viable Product)
- Validated learning
- Pivot or persevere

## Gestión tradicional

### PMBOK
- 10 áreas de conocimiento
- 5 grupos de procesos
- Gestión de alcance, tiempo, costo, calidad

### PRINCE2
- Procesos y temas
- Gestión por etapas
- Business case

## Planificación y estimación
- User stories y acceptance criteria
- Story points y planning poker
- T-shirt sizing
- Velocity tracking
- Release planning
- Roadmapping

## Gestión de riesgos
- Identificación de riesgos
- Matriz de probabilidad/impacto
- Mitigación y contingencia
- Risk register

## Herramientas
- **Gestión de proyectos**: Jira, Azure DevOps, Asana, Monday, Linear
- **Documentación**: Confluence, Notion, SharePoint
- **Comunicación**: Slack, Microsoft Teams, Discord
- **Diagramas**: Miro, Lucidchart, Figma
- **Time tracking**: Toggl, Harvest, Clockify

## Métricas de proyecto
- Velocity
- Lead time y cycle time
- Burndown/burnup charts
- Cumulative flow
- Defect escape rate
- Team health metrics

## Liderazgo técnico
- Mentoring y coaching
- Code reviews constructivos
- Toma de decisiones técnicas
- Comunicación efectiva
- Gestión de stakeholders
- Technical debt management
