# DevOps Enterprise

## Descripción
Habilidad para la implementación de prácticas DevOps, infraestructura como código y pipelines de CI/CD en entornos empresariales.

## Containers y orquestación
- **Docker**: Multi-stage builds, Docker Compose, optimización de imágenes
- **Kubernetes**: Deployments, Services, Ingress, ConfigMaps, Secrets
- **Helm**: Charts, releases, templating
- **Service Mesh**: Istio, Linkerd

## CI/CD
- **GitHub Actions**: Workflows, matrices, secrets
- **GitLab CI**: Pipelines, environments, auto-devops
- **Jenkins**: Pipelines as code, shared libraries
- **Azure DevOps**: Pipelines, releases, artifacts
- **ArgoCD**: GitOps, sync automático

## Infraestructura como Código (IaC)
- **Terraform**: Módulos, state management, workspaces
- **Pulumi**: Infraestructura con código generalista
- **AWS CDK**: Construct library
- **Ansible**: Configuration management, playbooks
- **CloudFormation**: Stacks, nested stacks

## Cloud providers
- **AWS**: EC2, ECS, EKS, Lambda, S3, RDS, DynamoDB
- **Azure**: AKS, App Service, Functions, Cosmos DB
- **GCP**: GKE, Cloud Run, Cloud SQL, BigQuery

## Monitoreo y observabilidad
- **Métricas**: Prometheus, Grafana, Datadog
- **Logging**: ELK Stack, Loki, Splunk
- **Tracing**: Jaeger, Zipkin, OpenTelemetry
- **Alertas**: PagerDuty, Opsgenie, VictorOps
- **SLOs/SLIs**: Error budgets, burn rate

## Seguridad en DevOps
- DevSecOps
- Escaneo de vulnerabilidades (Trivy, Snyk)
- Image scanning
- Secrets management (Vault, SOPS)
- Policy as Code (OPA, Kyverno)

## GitOps
- Control de versiones con Git como fuente de verdad
- Pull requests para cambios de infraestructura
- Automatización de despliegues
- Rollback automático
