# Investigación Técnica y Evaluación de Tecnologías

## Descripción
Habilidad para investigar y evaluar tecnologías, frameworks, herramientas y soluciones técnicas para un proyecto.

## Cuándo usarla
- Al seleccionar un stack tecnológico
- Al evaluar soluciones de terceros
- Al investigar problemas técnicos complejos
- Al comparar alternativas de implementación

## Herramientas
- **Documentación oficial**: Docs de tecnologías, especificaciones
- **Comunidades**: Stack Overflow, Reddit, Hacker News, Discord/Slack
- **Benchmarks**: TechEmpower, JSBench, DB-Engines
- **Análisis**: GitHub (stars, issues, actividad), npm/PyPI (descargas, mantenimiento)
- **Pruebas**: Proof of Concepts (PoC), prototipos

## Receta

### 1. Definir criterios de evaluación
- Rendimiento
- Escalabilidad
- Seguridad
- Facilidad de uso / curva de aprendizaje
- Comunidad y soporte
- Mantenimiento y longevidad
- Costo (licencias, infraestructura)
- Integración con stack existente

### 2. Identificar alternativas
- Mínimo 3 opciones a comparar
- Incluir opciones establecidas y emergentes
- Considerar soluciones build vs. buy

### 3. Investigar cada alternativa
- Documentación oficial
- Casos de uso reales
- Problemas conocidos (GitHub issues, foros)
- Rendimiento en benchmarks
- Seguridad (CVEs, historial de vulnerabilidades)

### 4. Crear Proof of Concept (PoC)
- Implementar un prototipo mínimo
- Probar funcionalidades críticas
- Medir rendimiento real
- Evaluar experiencia de desarrollo

### 5. Comparar y decidir
- Tabla comparativa con criterios ponderados
- Análisis de trade-offs
- Recomendación justificada
- Plan de migración si aplica

## Errores típicos
- ❌ Elegir tecnología por "hype" sin evaluar adecuadamente
- ❌ Ignorar la curva de aprendizaje del equipo
- ❌ No considerar el mantenimiento a largo plazo
- ❌ No hacer PoC antes de comprometerse
- ❌ Ignorar la comunidad y ecosistema
- ❌ No evaluar costos ocultos (licencias, infraestructura)

## Checklist
- [ ] Criterios de evaluación definidos
- [ ] Mínimo 3 alternativas identificadas
- [ ] Documentación oficial revisada
- [ ] Benchmarks consultados
- [ ] PoC implementado
- [ ] Tabla comparativa completada
- [ ] Recomendación documentada
- [ ] Plan de migración considerado
