# Herramientas

## Stack tecnológico principal
- Frontend: Next.js
- Backend: FastAPI y Spring Boot
- Base de datos: PostgreSQL + MongoDB o MongoDB único
- Autenticación: Google OAuth 2.0 + JWT
- Contenerización: Docker + docker-compose
- Control de versiones: Git + GitHub

## Herramientas de apoyo
- Figma o mockups para diseño visual
- Draw.io para diagramas
- GitHub para repositorio y Wiki
- Swagger/OpenAPI para documentación de APIs
- Visual Studio Code para desarrollo

## Justificación
Estas herramientas permiten construir una solución moderna, organizada y fácil de documentar para una plataforma web de repostería con enfoque académico y profesional.
