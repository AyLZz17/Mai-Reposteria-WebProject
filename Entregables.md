# Entregables

## Wiki del proyecto
Este repositorio ya incluye una estructura base para una Wiki de GitHub, con páginas para:
- Inicio
- Arquitectura
- Historias de usuario
- Requisitos no funcionales
- Diagramas
- Stakeholders
- Entregables

## Material para sustentación
Puedes complementar esta Wiki con:
- diapositivas en PowerPoint o Google Slides
- PDF final de presentación
- resumen ejecutivo para la sustentación

## Ejemplo de referencia
- [RepasoSoftware Wiki](https://github.com/Aegisystem/RepasoSoftware/wiki)

## Recomendación
Para completar el entregable final, se recomienda dejar:
1. la Wiki con toda la documentación
2. una presentación breve con los puntos principales
3. un resumen en el README con enlaces directos
